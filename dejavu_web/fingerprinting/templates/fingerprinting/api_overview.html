Swagger UI (Interactive) ReDoc (Documentation)

API Overview

The Dejavu API is organized into the following sections:

Authentication

Authentication endpoints for user login, registration, and token management.

POST /fingerprinting/api/auth/login/ - Log in and get access tokens

POST /fingerprinting/api/auth/logout/ - Log out and invalidate tokens

GET /fingerprinting/api/auth/me/ - Get current user information

Music Catalog

Endpoints for managing tracks, albums, and artists in your music library.

GET /fingerprinting/api/catalog/tracks/ - List all tracks

GET /fingerprinting/api/catalog/albums/ - List all albums

GET /fingerprinting/api/catalog/artists/ - List all artists

Fingerprinting & Recognition

Core functionality for fingerprinting audio files and recognizing unknown audio.

POST /fingerprinting/fingerprint/ - Fingerprint an audio file

POST /fingerprinting/recognize/ - Recognize an audio file

Monitoring

Endpoints for monitoring radio airplay and logging play events.

GET /fingerprinting/api/monitoring/airplay-logs/ - List all airplay logs

GET /fingerprinting/api/monitoring/stations/ - List all stations

Getting Started

To explore all API endpoints interactively, use the Swagger UI, which allows you to:

  • View detailed documentation for each endpoint
  • Test API calls directly from your browser
  • Understand request/response formats

For a more documentation-focused view, try ReDoc, which provides a clean, responsive interface for API documentation.
